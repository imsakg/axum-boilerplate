# Reconstructed local history

This branch is a user-requested historical reconstruction, prepared in October
2026, not evidence that these changes were developed in 2022–2023. Both author
and committer timestamps follow a deliberately chosen weekday/evening schedule.
The initial twelve commits retain their original trees and messages plus an
`Original-Commit` provenance trailer; their original dates were 29–30 July 2023.
The untouched `main` branch retains those original commits and its unfinished
working-tree changes. No upstream history has been changed or pushed.

Subsequent commits introduce real code, regression tests, and documentation.
Commit subjects describe actual changes, not simulated work. Dependency lockfile
resolution and test results come from the current toolchain, so the historical
dates do not imply a historically reproducible build environment.
